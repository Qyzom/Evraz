# ЕВРАЗ • АСУ ГТК «ESIM DISPATCH»

Интерактивный симулятор диспетчеризации горно-транспортного комплекса открытых горных работ. Проект разработан в рамках решения кейса «Карьерная перспектива».

Онлайн-демо: **https://qyzom.github.io/Evraz/**

## Возможности

- **3D WebGL-модель карьера:** Уступы, бермы безопасности, два независимых капитальных съезда (Западный спуск / Восточный подъем), дробильный комплекс ГОФ-1, внешний отвал вскрыши, АЗС и сервисный ангар РМЦ.
- **Диспетчеризация автопарка:** Управление парком из 12 карьерных самосвалов БелАЗ (модели 75131 на 130 т и 75313 на 240 т) и 4 экскаваторов Liebherr (R 9250 и R 9400).
- **Режимы управления:**
  - *Ручной диспетчер:* адресные радиоприказы самосвалам, ручное перераспределение грузопотоков.
  - *АСУ ГТК (Автомат):* алгоритмическая балансировка очередей, предотвращение встречных заторов и простоев оборудования.
- **Финансовая и производственная аналитика:** Расчет операционной маржи смены, учет простоев по официальным тарифам, штрафы за засор дробилки вскрышей, графики добычи и готовности парка.
- **Управление камерой:** Свободный осмотр, фиксация камеры на любом самосвале с поддержкой зума и вращения без потери фокуса, сброс по `Escape`.

## Управление

- `ЛКМ по самосвалу / кнопка «ФОКУС»` — захват камеры и панель приказа.
- `Колесико / Зажатая мышь` — свободный зум и вращение камеры вокруг выбранного объекта.
- `Escape` — моментальный сброс в свободный режим обзора.
- `Пробел` — пауза и возобновление хода смены.
- `0..9` — быстрые точки внимания (карьер, забои 1-4, ГОФ, отвал, АЗС, РМЦ, ЦУП).

## Локальный запуск

```bash
python3 -m http.server 8080
```
Открыть в браузере: `http://localhost:8080`
