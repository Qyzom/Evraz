# Evraz

Интерактивный 3D-симулятор диспетчеризации горно-транспортного комплекса открытых горных работ для кейса «Карьерная перспектива».

**Онлайн-демо:** [https://qyzom.github.io/Evraz/](https://qyzom.github.io/Evraz/)

---

### Правовой статус и брендинг

Наименование «ЕВРАЗ», элементы айдентики, корпоративные цвета и логотипы являются зарегистрированными товарными знаками ООО «ЕВРАЗ». Проект учебный, автор не является правообладателем этих знаков. Использование брендинга и материалов третьими лицами без согласия правообладателя запрещено.
